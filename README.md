Estou desenvolvendo o RPM Player, um player de música para PC que reúne dois interesses meus: design de interfaces e desenvolvimento de software.

O projeto conta com biblioteca por pastas, capas de álbuns, favoritos, playlists e equalizador. Também implementei painéis recolhíveis, navegação por letras e personalização de cores, textos e volume abaixo de 1%.

Utilizei JavaScript, Electron, HTML, CSS e Web Audio API. A integração com playlists do YouTube Music tem o fluxo de conexão Google implementado, mas ainda precisa de configuração e validação com uma conta real.

O RPM Player está em evolução. Os testes no ambiente de desenvolvimento passaram; a validação da instalação e execução no Windows é uma das próximas etapas.

Quero compartilhar esse processo e receber sugestões sobre interface, acessibilidade e organização da biblioteca musical.
